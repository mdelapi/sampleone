# docs/

Material de apoio ao pacote `sampleone`, para navegação no GitHub — **não faz
parte do pacote R instalável** (está listado em `.Rbuildignore`).

| Arquivo | Conteúdo |
|---|---|
| `REFERENCIA_FUNCOES_sampleone.md` | Referência das 46 funções (inputs, descrição, como chamar, dependências), em Markdown |
| `sampleone_referencia_funcoes.xlsx` | A mesma referência, em planilha (filtrável/ordenável) |
| `VALIDACAO_LISTA01.md` | Validação cega do pacote contra a Lista 1 (Temas 1-5) de exercícios do Prof. Mariano Martínez Espinosa |

Para a documentação oficial do pacote (a que aparece em `?funcao` e
`vignette("catalogo-formulas")` dentro do R), ver `man/` e `vignettes/`.
